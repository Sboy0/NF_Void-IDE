# 🚀 NF_Void IDE

Лёгкая интегрированная среда разработки с локальным искусственным интеллектом на базе Ollama. Создана как бесплатная альтернатива коммерческим AI-IDE вроде Cursor.

![Python](https://img.shields.io/badge/Python-3.8+-blue.svg)
![License](https://img.shields.io/badge/License-Open-green.svg)
![AI](https://img.shields.io/badge/AI-Ollama-orange.svg)

---

## ✨ Возможности

- **🤖 Локальный AI помощник** - Работает на Ollama (Llama 3.2, Phi 3). Полностью офлайн, без API-ключей и платежей.
- **🐍 Поддержка Python** - Запуск кода с выводом в отдельной панели.
- **📜 Поддержка JavaScript** - Выполнение через Node.js с поддержкой console.log.
- **🌐 Предпросмотр HTML** - Просмотр HTML файлов через встроенный HTTP-сервер.
- **💾 Автосохранение** - Код автоматически сохраняется при переключении между файлами.
- **📁 Проводник файлов** - Управление файлами проекта в левой панели.
- **⚠️ Обнаружение ошибок** - Автоматический парсинг ошибок с номерами строк.
- **💻 Встроенный терминал** - Выполнение системных команд (pip install, python, node и др.).
- **📥 Панель Input** - Предварительный ввод данных для программ с input()/prompt().
- **🖥️ Десктопный режим** - Запуск как нативное приложение (не в браузере).

## 🚀 Установка

### 1. Клонируйте или скачайте проект

```bash
git clone https://github.com/yourusername/nf-void-ide.git
cd nf-void-ide
```

### 2. Установите зависимости Python

```bash
pip install -r requirements.txt
```

### 3. Установите Ollama (обязательно для AI)

1. Скачайте с: https://ollama.com/
2. Установите и запустите установщик
3. Загрузите модель:
   ```bash
   ollama pull phi3
   ```
   Или для лучшего качества:
   ```bash
   ollama pull llama3.2
   ```

### 4. Установите Node.js (опционально, для JavaScript)

Скачайте с: https://nodejs.org/

## 🎯 Использование

### Запуск как десктопное приложение (рекомендуется)

```bash
start_cursor.bat
```

Или вручную:
```bash
python desktop_app.py
```

### Запуск в браузере

```bash
python main.py
```

Затем откройте: `http://127.0.0.1:8000`

## 🤖 Настройка AI

Отредактируйте `desktop_app.py` или `main.py` для изменения настроек AI:

```python

OLLAMA_HOST = "http://localhost:11434"  # Сервер Ollama
```

## 💡 Использование панели Input

Панель Input позволяет заранее ввести данные для программ с `input()` или `prompt()`:

1. Откройте вкладку **Input** внизу
2. Введите значения (по одному на строку)
3. Нажмите **Enter** после каждого значения
4. Нажмите **"✓ Использовать Input при запуске"**
5. Нажмите **▶ Run**

Данные будут автоматически переданы в программу!

## 🐛 Решение проблем

### AI не отвечает

```bash
# Проверьте запущен ли Ollama
ollama list

# Перезапустите сервер Ollama
ollama serve
```

### Порт уже занят

```bash
# Измените порт в desktop_app.py
uvicorn.run(app, host="127.0.0.1", port=8001)
```

### Модуль не найден

```bash
# Переустановите зависимости
pip install -r requirements.txt --upgrade
```

### Панель Input не работает

1. Убедитесь, что нажали **Enter** после ввода
2. Нажмите кнопку **"✓ Использовать Input при запуске"**
3. Проверьте, что значения появились в списке истории
